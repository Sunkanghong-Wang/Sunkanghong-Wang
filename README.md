# Hi there, I'm Sunkanghong Wang 👋

🎓 **PhD Student · The Hong Kong Polytechnic University**

I am a PhD student in the Department of Logistics and Maritime Studies, Faculty of Business, at The Hong Kong Polytechnic University (PolyU).

### 🔬 Research Interests

- **Problems:** Bin packing, cutting, and knapsack problems.
- **Methods:** Integer programming, dynamic programming, branch-and-bound, branch-and-price, and Benders decomposition.
- **Research software:** Open-source implementations of exact optimization algorithms.

### 🛠️ Tech Stack

`C++` · `Java` · `Python` · `MATLAB`

### 📦 Selected Projects

| Project | Description |
| --- | --- |
| [PrecPack](https://github.com/Sunkanghong-Wang/PrecPack) | An exact solver for bin packing with generalized precedence constraints. |
| [EAs_For_2KPs](https://github.com/Sunkanghong-Wang/EAs_For_2KPs) | Exact algorithms for two-dimensional knapsack problems. |
| [EATKG_For_2KPG](https://github.com/Sunkanghong-Wang/EATKG_For_2KPG) | An exact algorithm for the two-dimensional knapsack problem with guillotine constraints. |
